# Trabalho no Delfos

- Use `main` como base e faça os commits solicitados na branch local `main`, conforme orientação do responsável pelo projeto.
- Não crie ou faça merge de PRs por conta própria: o responsável faz essa etapa. Não publique nem envie commits para outra branch sem solicitação.
- Antes de começar, atualize a referência `origin/main` e preserve alterações locais. Nunca force push.
- Preserve registros, anexos, preferências e compatibilidade dos backups nas mudanças de interface.
- Valide mudanças de navegação e formulários no navegador, incluindo teclado e largura de celular.
